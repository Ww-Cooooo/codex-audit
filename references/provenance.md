# 来源与改编

本包复用作者自己的 Agent Check 就地恢复草稿中的方法，重新组织为面向 Codex 的独立审查入口：

| 来源方法 | 本包采用方式 |
| --- | --- |
| 原要求、实际行为和产物优先 | 先找可观察偏差，再沿来源取证 |
| 第一处漂移及后续沿用 | 区分用户决定、举例、Agent 建议和失效假设 |
| 纠正承诺与下一次动作比较 | 以实际采用结束修复，避免只更新解释 |
| 原 Agent 在原对话继续任务 | 保留为恢复验证条件，不限制获准的多案例只读审查 |
| 文件存在、读取、加载和结果分开 | 用于配置、Skill、记忆和测试结论 |
| 可逆调整与有限因果判断 | 原因未知可比较；不把相关性或模拟通过当作普遍恢复 |

Agent Check 原稿已经涵盖单项任务、单个聊天、项目和多项目问题。本包的区别在于审查本身可作为完整交付，并加入按范围采集 Codex 元数据、定位获准原文与生成续接依据的工具；不宣称首创跨对话审查。

More Than Yes 对本次设计的影响是以目标、证据和实际结果做独立判断，并处理重要遗漏。使用本包不依赖它或任何私人记忆。采集器和本包测试为本次新实现，没有复制旧的机器专用采集脚本。旧稿测试与其他方法的历史成绩不作为本包的验证结果。

本包未包含私人聊天、旧项目路径、原始案例或账号资料。项目名称为 Codex Audit，按 [MIT 许可证](../LICENSE) 公开分发。Agent Check 草稿不是运行依赖；公开试用者不需要访问该稿或作者的开发聊天。
